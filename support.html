📌 产品介绍

WhatsApp外贸翻译助手是 Chrome 浏览器扩展，用于 web.whatsapp.com 网页端实时翻译聊天消息（含文字与语音），帮助外贸人员快速与海外客户沟通。

使用前须知：翻译与语音功能需要登录账号且套餐有效。首次使用请在插件选项页注册或登录；未登录状态下插件不会翻译聊天内容。

❓ 常见问题 FAQ

1. 插件不生效，看不到翻译？

请按以下顺序排查：

  1. 确认已登录且套餐有效（最常见原因）：打开插件选项页查看账号状态。未登录或套餐到期时，插件会自动停用翻译功能，聊天消息不会显示译文。
  2. 确认打开的是 web.whatsapp.com，WhatsApp 桌面客户端和手机端无效。
  3. 刷新 WhatsApp 网页，使插件重新加载会话状态。
  4. 确认插件已在 chrome://extensions 启用。
  5. 确认选项页中的「全局开关」和「自动翻译」已开启。
  6. 关闭其他翻译类扩展，避免相互冲突。

2. 翻译失败 / 无返回结果

  1. 检查网络连接——翻译请求需要联网发送至翻译服务。
  2. 确认账号未到期、额度未用尽（到期提示「套餐已到期」时请续订）。
  3. 部分特殊语种、超长文本可能翻译超时（默认超时 8 秒），可尝试刷新聊天页面后重试。
  4. 如您使用了自行配置的第三方 API Key，请确认 Key 有效、余额充足、所选服务商可访问。
  5. 可在选项页切换翻译服务商后重试。

3. 语音消息翻译失败 / 没有「翻译语音」按钮

  1. 语音翻译需要专业版套餐且有剩余语音时长，请先在选项页确认套餐与余额。
  2. 「翻译语音」按钮仅在客户发送的语音消息下方显示，自己的语音不出按钮。
  3. 若提示「未捕获到语音数据」，请先手动播放一次该条语音，再点击「翻译语音」重试。
  4. 语音翻译功能独立于文字翻译开关，无需开启自动翻译即可使用。

4. 登录、账号与设备管理

  1. 注册需要邮箱接收验证码；验证码由服务端发送，插件不保存明文验证码。
  2. 可在选项页「设备管理」查看已授权设备，移除不再使用的设备。
  3. 忘记密码或需要注销账号，请在选项页「账号管理」中操作；如遇到障碍，请邮件联系我们。

5. 插件如何关闭 / 卸载？

在 Chrome 扩展管理页面（chrome://extensions）找到本插件，可关闭或直接移除。

卸载会清除本机浏览器中的全部本地数据（配置、登录会话、客户语言偏好、翻译缓存）。注意：服务端账号资料、常用短语及订阅信息不会因卸载扩展而删除。如需彻底删除，请先在插件内注销账号，或联系我们协助处理。

6. 数据隐私与开关

  1. 自动翻译、发送前翻译、语音翻译和本地缓存均可在选项页独立关闭或清除。
  2. 关闭全部翻译开关后，插件不会读取或发送聊天内容。
  3. 详见 隐私政策（含数据收集醒目披露）。
