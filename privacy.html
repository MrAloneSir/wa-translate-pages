一、引言

WhatsApp 外贸翻译助手（以下简称“本扩展”）是一款 Chrome 浏览器扩展程序，用于为 web.whatsapp.com 网页版提供聊天消息实时双语翻译、发送前翻译、语音消息翻译及相关的外贸沟通辅助功能。

本隐私政策说明本扩展收集哪些数据、为何收集、发送给谁、保存多久，以及您可以如何控制。使用本扩展即表示您已阅读并同意本政策；如果您不同意，请停止使用并卸载本扩展。

本扩展的单一用途是：协助外贸用户在 WhatsApp 网页版上跨越语言障碍完成客户沟通。本政策所列全部数据处理行为，均是为了实现、维护这一用途所必需的翻译、授权与体验功能，不用于广告、画像分析或与翻译无关的目的。

二、我们收集的数据及方式

2.1 聊天文本与输入框文本

  • 当您在 web.whatsapp.com 打开会话时，本扩展会读取当前页面可见的聊天消息文字，用于判断是否需要翻译并展示译文；滚动时只处理新进入可视区域的消息。
  • 当您开启“发送前翻译”（autoTranslateOnSend）时，本扩展会读取您在输入框中尚未发送的文字，翻译后回填，待您确认后再由您自行发送。
  • 当您在悬停模式下把鼠标移到消息上，或手动点击翻译按钮时，相关消息文字会被读取并翻译。
  • 上述文本会被发送到本扩展的翻译服务进行处理，处理后界面展示译文。详细接收方见第四节。

2.2 语音消息

  • 仅当您在某条语音消息下方点击“翻译语音”按钮时，本扩展才会通过捕获该条语音播放时的音频数据，获得音频文件。
  • 音频文件会被上传到本扩展的语音转写服务，由服务端完成语音识别与翻译，并将译文返回显示。
  • 语音翻译需要登录、有效专业版套餐及足够的剩余语音时长；服务端会按实际转写时长计算用量。
  • 本扩展不会在后台批量录制或上传语音；只有您主动点击的语音才会被处理。

2.3 账号与订阅信息

  • 注册时：邮箱地址、密码、邮箱验证码、邀请码（选填）。
  • 登录时：邮箱地址、密码。
  • 登录成功后：服务端返回的会话令牌（Token）、用户 ID、昵称、套餐与授权状态。
  • 账号管理：修改密码、注销账号时提交的密码或确认信息。
  • 验证码由服务端发送并校验，本扩展不在本地保存明文验证码；密码仅用于提交给服务端校验，不会以明文形式保存在浏览器或日志中。
  • 登录状态、令牌等保存在浏览器的 chrome.storage.local（键名 wa_account_session）。会话过期或被注销后会被清除。

2.4 设备信息

  • 首次使用时，本扩展会生成一个随机设备 ID（UUID，保存在本机 wa_device_id），用于标识您的安装实例。
  • 登录和设备管理时，会收集并上传：设备名称、浏览器名称与版本、操作系统及版本。在支持的浏览器上，还会通过 Client Hints 获取更精确的操作系统平台与版本信息（platform、platformVersion）。
  • 这些信息用于账号授权校验、设备列表展示与移除、异常登录防护。您可以在选项页的“设备管理”中查看并移除已授权设备。

2.5 客户标识与语言偏好

  • 为自动判断客户所用语言、以及在会话顶部显示客户当地时间，本扩展会在本机读取当前会话对象的手机号或显示名称，并根据国家/地区区号推断语言与时区。
  • 如果您在会话中手动指定了客户的语言，本扩展会把“客户手机号或名称 → 语言”的对应关系保存在本机 chrome.storage.local（键名 wa_chat_languages）。
  • 这些信息仅保存在您的浏览器本地，不会上传至服务器。

2.6 本地配置与 API 凭据

  • 翻译偏好（语言、显示模式、字体、缓存开关与有效期、故障转移、自定义提示词等）保存在本机 chrome.storage.local（键名 wa_trans_config）。
  • 如果您选择使用自有 API Key 的翻译服务（OpenAI、DeepL、Groq、Mistral、Anthropic、通义千问、百度文心等），密钥保存在本机的 providerCredentials 配置中，不会上传至本扩展的服务端；但相应的翻译请求会从您的浏览器直接发往该服务商，并携带您的 API Key。请妥善保管密钥。

2.7 常用短语

  • 当您在选项页添加、编辑或删除常用短语时，短语文本会通过账号接口同步至本扩展服务端，用于在其他会话或设备上使用。
  • 常用短语内容也会缓存到本机 waCommonPhrases。

三、数据使用目的

本扩展仅在以下范围内使用您的数据：

  1. 完成翻译：将聊天文本、输入框文本或语音内容即时翻译，并展示结果。
  2. 账号与授权：验证登录状态、套餐与功能权限、管理设备与用量。
  3. 提升翻译一致性：保存您设定的语言与风格偏好、常用短语。
  4. 本地体验优化：缓存翻译结果以减少重复请求、显示客户当地时间。

本扩展不会将您的数据用于广告投放、用户画像、自动化营销、出售或出租给第三方，也不会用于与本用途无关的分析。

四、数据的共享与第三方服务

本扩展可能把数据处理请求发送给以下接收方。除下列情形外，我们不会共享您的数据。

  • 域名：whatsapp-trade-translator-api.jin623935663.workers.dev

  • 请求携带登录令牌用于身份校验。
  • 默认 Google 翻译通道的聊天文本也经由该服务中转，并非直接从您的浏览器发往 Google。
  • 该服务由本扩展开发者运营，仅用于本扩展功能实现。

六、您的数据控制权与选择

  1. 关闭自动翻译 / 全局开关：在选项页关闭后，本扩展不会读取和发送聊天文本进行翻译。
  2. 关闭发送前翻译：关闭后，输入框中的待发送文字不会被读取或翻译。
  3. 不使用语音翻译：不点击“翻译语音”按钮，本扩展不会捕获或上传任何语音。
  4. 关闭或清除本地缓存：在选项页关闭缓存或点击“清除缓存”，可删除已保存的原文与译文。
  5. 退出登录 / 注销账号：退出登录后翻译功能停用；账号管理页提供注销入口。
  6. 移除设备：在“设备管理”中移除不再使用的设备授权。
  7. 卸载扩展：通过浏览器扩展管理页卸载，清除全部本地数据。
  8. 使用自有 API Key：如果您不希望聊天文本经过本扩展的服务端，可在选项页配置自有 API Key 的翻译服务商，文本将从浏览器直连该服务商（此时请自行评估该服务商的隐私政策）。
  9. 本地偏好设置：语言偏好、客户时区等信息仅存在本机，清除浏览器存储即可删除。

关于“离线模式”：机器翻译需要将文本发送给翻译服务处理，因此本扩展目前不提供可完成翻译的纯离线模式；但关闭翻译相关开关后，本扩展不会传输聊天内容。

七、扩展权限说明

本扩展申请以下权限，均用于上述用途：

  • storage：保存配置、会话、缓存与语言偏好。
  • scripting / 内容脚本：仅在 web.whatsapp.com 页面注入，读取页面聊天内容并显示译文。
  • 主机权限：web.whatsapp.com（页面本身）；*.workers.dev（本扩展账号/翻译/语音服务）；以及您在选项页可能选用的第三方翻译 API 域名（Google、DeepL、OpenAI、Groq、Mistral、Anthropic、通义千问、百度文心）。开发环境还会申请 localhost 地址用于本地调试。

本扩展不会在上述范围之外的网站上运行或读取数据。

八、儿童隐私
